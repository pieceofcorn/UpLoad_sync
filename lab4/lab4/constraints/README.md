# 板级约束

lab4.xdc用于本次EDK-A7-Minisys-I V3.2-100T配置，端口对应lab4_top；主时钟Y18、100MHz，周期10ns。文件名统一为lab4.xdc，引脚与I/O设置保持本次试跑配置。

该配置已完成所列单板功能试验，各Bank实际供电尚未独立测量，功能通过不能替代完整电气确认。适配其他板卡或修订版需重新核对，不直接套用。

GUI可按手册在仿真后加入此约束；create_project.tcl会自动加入，不需要再选择其他约束文件。SW23为预留输入，未使用时可能在综合中裁剪；CFGBVS/CONFIG_VOLTAGE及外部I/O延迟未编造数值。
